# Getting help

- **Questions and problems with the program:** open an issue on GitHub
  (<https://github.com/SedicCodeStudio/scs-scanner/issues>) and attach the diagnostic log `~/.scs-scanner/logs/scs.log`
  if the program showed an error. The log contains no scan results.
- **A finding that is wrong (false positive):** use the issue form "False positive". Do not upload private files.
- **A security problem in the scanner itself:** please report it privately – see [SECURITY.md](SECURITY.md).
- **You think you are being spied on:** read [docs/WHAT-TO-DO.md](docs/WHAT-TO-DO.md). Journalists, activists and other
  people at risk get free, confidential help from the Access Now Digital Security Helpline
  (<https://www.accessnow.org/help/>) and the Amnesty International Security Lab (<https://securitylab.amnesty.org/get-help/>).
- **Business enquiries:** info@sediccodestudio.de
